### 🚀 Featured Projects

#### 🪟 [VLM-Viewport-Optimizer](https://github.com/ajinkya263/vlm-viewport-optimizer)
A production-grade browser-automation framework that lets vision AI agents (Claude Computer Use, GPT-4o) navigate the web by screenshot while cutting vision-input **tokens by ~60%**. Set-of-Mark labeling, differential delta-frame rendering, and a macro→zoom hierarchy — with its own measured token-savings scorecard.
- **Stack:** Python · Playwright · FastAPI · OpenCV · NumPy
- 🔗 [Code & docs](https://github.com/ajinkya263/vlm-viewport-optimizer)

#### 🏠 [Affordable Housing Visibility](https://github.com/kirbb3/H4H-2026---team-Baka) &nbsp;·&nbsp; <sub>Hack for Humanity 2026</sub>
A friendlier front door to government & affordable-housing information — so people can find what they need instead of getting lost in cluttered official websites. Built with a team at SCU's Hack for Humanity hackathon.
- **Stack:** TypeScript front-end · Python back-end
- 🔗 [Devpost](https://devpost.com/software/affordable-housing-visibility) &nbsp;·&nbsp; [Code](https://github.com/kirbb3/H4H-2026---team-Baka)

#### 🇮🇳 [IndianPrograms.com](https://indianprograms.com)
A platform to discover Indian cultural events across America — browse and find programs near you, backed by a live events database.
- **Stack:** Next.js · TypeScript · Supabase
- 🔗 [Live site](https://indianprograms.com) &nbsp;·&nbsp; [Code](https://github.com/ajinkya263/indianprograms)
